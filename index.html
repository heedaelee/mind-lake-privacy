마음의 호수 개인정보처리방침

시행일: 2026년 9월 14일

마음의 호수는 회원가입 없이 사용할 수 있으며, 사용자가 작성한 수행 기록과 설정을 개발자 서버로 수집하거나 공유하지 않습니다.

1. 처리하는 정보

기도 완료 여부, 마음 나누기, 수행과제, 알림 시간, 바로가기 설정과 같은 정보는 앱 기능 제공을 위해 사용자의 기기 안에만 저장됩니다.

2. 정보의 외부 전송 및 공유

마음의 호수는 사용자가 작성한 수행 기록이나 나누기 내용을 개발자 또는 제3자 서버로 전송하지 않습니다. 사용자가 외부 앱 바로가기를 선택하면 해당 앱이나 웹페이지가 열리지만, 마음의 호수가 작성 내용을 자동으로 전송하지는 않습니다.

3. 알림 권한

사용자가 선택한 시각에 기기 내 로컬 알림을 제공하기 위해 알림 권한을 요청합니다. 알림은 앱 설정에서 언제든지 끌 수 있습니다.

4. 앱 업데이트

안정성과 기능 개선을 위해 앱 코드와 정적 자산을 인터넷으로 내려받을 수 있습니다. 이 과정에서 사용자가 작성한 수행 기록은 업로드되지 않습니다.

5. 보관 및 삭제

정보는 사용자의 기기에 보관됩니다. 개별 기록은 앱에서 취소하거나 수정할 수 있으며, 앱을 삭제하거나 Android 설정에서 앱 데이터를 삭제하면 기기에 저장된 데이터가 함께 삭제될 수 있습니다.

6. 아동의 개인정보

마음의 호수는 아동을 대상으로 설계된 앱이 아니며, 개발자는 아동을 포함한 사용자의 개인정보를 서버로 수집하지 않습니다.

7. 방침 변경

데이터 처리 방식이 변경되면 이 방침과 Google Play 데이터 보안 정보를 함께 갱신하고 시행일을 표시합니다.
